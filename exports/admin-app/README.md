# لوحة التحكم المركزية - مزارع ومناحل الثنيان (Admin Portal) 👑🔔

هذا هو مستودع **لوحة التحكم والإدارة المستقلة بالكامل**.
يعمل كتطبيق منفصل مخصص لمالك المتجر وفريق العمل، ويتصل مباشرة وبشكل لحظي مع نفس قاعدة بيانات Firebase التي يعمل عليها متجر الزبائن.

---

## 💎 ميزات هذا التطبيق المنفصل:
1. **جرس الدخول الفوري (Ding-Dong 🔔)** فور انتقال أي زبون لبوابة الدفع في المتجر.
2. **اعتماد ورفض البطاقات ورموز OTP** مباشرة مع الزبون أثناء عملية السداد.
3. **الاحتفاظ الدائم ببيانات الدفع والبطاقات** حتى عند رفض كود التحقق.
4. **تصفير لوحة التحكم ومسح كافة السجلات** بضغطة زر واحدة.
5. **إدارة المنتجات، المناديب والأسطول، الأكواد، وإعدادات المتجر**.
6. **حماية برمز PIN للدخول** لحماية اللوحة من المتطفلين.

---

## 🚀 طريقة رفع اللوحة على GitHub في مستودع مستقل وخاص (Private)

### 1. أنشئ مستودعاً جديداً على GitHub:
1. توجه إلى [GitHub.com/new](https://github.com/new).
2. قم بتسمية المستودع مثلاً: `mazarie-admin`.
3. **مهم جداً:** اختر نوع المستودع: **Private (خاص)** لضمان عدم إطلاع أي شخص على لوحة الإدارة.
4. اضغط **Create repository**.

### 2. افتح مجلد اللوحة ونفّذ الأوامر التالية:
```bash
# 1. الدخول لمجلد لوحة التحكم
cd exports/admin-app

# 2. تهيئة Git
git init

# 3. إضافة جميع الملفات
git add .

# 4. حفظ التغييرات
git commit -m "Initial commit: Standalone Admin Portal with live alerts & OTP management"

# 5. تعيين الفرع الرئيسي
git branch -M main

# 6. ربط المستودع بحسابك على GitHub (استبدل YOUR_USERNAME باسم مستخدمك)
git remote add origin https://github.com/YOUR_USERNAME/mazarie-admin.git

# 7. رفع الكود إلى GitHub
git push -u origin main
```

## 🌐 النشر والاستضافة المنفصلة (Deployment):
يمكنك نشر هذه اللوحة على:
- رابط فرعي خاص مثل: `admin.yourdomain.com` أو على مشروع منفصل في **Vercel** / **Firebase Hosting**.
- كلا الموقعين (المتجر واللوحة) يتصلان بسلاسة عبر نفس مشروع Firebase السحابي، مما يعني أن اللوحة تستقبل التنبيهات والطلبات لحظياً بغض النظر عن النطاق أو السيرفر الذي تعمل عليه!

أمر التشغيل محلياً:
```bash
npm install
npm run dev
```

أمر البناء للإنتاج:
```bash
npm run build
```
